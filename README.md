# Alamelu V — Portfolio Landing Page

Live demo: https://alamelu-veerapandi.aalamelu1012.chatgpt.site/

## Run locally
Extract this ZIP and open index.html in your browser. No installation or build is required. An internet connection loads Google Fonts and opens external project links.

## Features
Semantic HTML5 sections, CSS Flexbox and Grid, responsive layouts, smooth section navigation, project details dialog, skill explorer and optional background audio.

## Files
- index.html: page content
- immersive.css and landing.css: visual design and single-page layout
- immersive.js: navigation and interactive controls
- project-modal.js and related CSS: project details dialog
- images/ and audio/: local assets

## Upload to GitHub
1. Extract this ZIP using Extract All.
2. Create a public repository named alamelu-portfolio.
3. Select Add file > Upload files.
4. Drag all files and the images/audio folders from the extracted folder into the upload area. Upload the contents, not the ZIP file.
5. Commit the files.
6. Copy the repository URL into Link to your work. Keep the live demo URL in Live demo link.

Review and understand the source before submitting it for your internship, and follow your programme's rules about assisted work.
